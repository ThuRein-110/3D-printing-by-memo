# Eight-at-a-time Creality reference showcase

The user requested eight random model examples and “See more” without leaving the MEMO site. A manually curated pool of 16 public Creality Cloud model references supports that behavior. The exact source links, creator attribution and observed license labels are in [the idempotent reference seed](../supabase/seed/creality-showcase.sql), checked on 6 November 2026.

These records contain factual names, attribution and source/license links only. No photographs, descriptions, model geometry or downloadable archives were copied. The neutral MEMO artwork is clearly reference artwork, not a claimed preview of the external model. Cards open local `/models/[id]` pages. The original source opens only when someone explicitly chooses its source link. Several examined sources state personal-use/noncommercial restrictions, for example [this model's license](https://www.crealitycloud.com/model-detail/ghost-stress-toy). License observations are not a shop entitlement or commercial approval; even the source labeled CC0 stays non-orderable pending a separate printability/file review.

Migration `011` adds `showcase_visible` independently of sales publication. A database check requires showcase cards to have sales visibility, availability, commercial approval and geometry preview disabled, no image/model assets, no price and no lead-time promise. The commercial `selectedCatalog`/quotation checks remain unchanged and reject reference-only IDs. Existing unapproved internal drafts remain hidden unless staff explicitly publishes the reference-only flag. No commercial license review is fabricated for this curation.

`browse_catalog` returns batches of eight with a fresh random UUID seed per page visit. Hash ordering is stable for that seed, so appending page two does not reshuffle or repeat page one while the catalog is unchanged. Search/category/price filters run server-side before selection. “See more models” appends the next batch inline on both the homepage and `/models`; exhausted feeds hide the button. The regular full-catalog link also stays on MEMO. Database writes and reference-mode configuration remain MFA-admin-only; the browse RPC is callable only by the server service role.

Apply migration 011 with the normal migration runner, then apply only `supabase/seed/creality-showcase.sql` to populate these references. The seed inserts fixed IDs with `on conflict do nothing`; it does not overwrite administrator edits or replay inventory defaults. It updates only search text for the seeded IDs. Never use a production reset. Existing orders, pricing versions and accepted quote snapshots are untouched.

To offer printing later, staff must obtain the necessary commercial rights, review the actual model and printability, supply authorized images/files where needed, and switch the record out of reference-only mode before commercial publication. An external provider API and image hotlinking are not part of this implementation.

Verification: 105 unit/database tests and 18 desktop/mobile browser tests cover the original workflows plus reference-mode constraints, rejection of reference-only orders, RLS, seeded random ordering, eight-card batches, duplicate-free incremental loading, and local reference detail routes. Two connected non-production scenarios remain skipped without test credentials. Lint, strict TypeScript, production builds and dependency audit are checked alongside deployment.
