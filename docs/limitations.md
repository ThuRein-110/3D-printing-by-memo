# Current limits and external verification gates

The production upgrade implements the six-step studio, typed English/Thai/Myanmar/Simplified Chinese UI, light/dark/system appearance, private image uploads, consented Meshy GLB jobs, real progress/credit telemetry, safe retries/cancellation, bounded GLB transforms, STL export, admin model review, dedicated sanitized filament media, structured configuration forms, monthly allowances/daily quotas and protection of internal quote costs. Existing accounting/stock/quotation/order/payment/PDF functions remain available.

This does **not** establish a verified live provider connection or production redeployment. The operator reports Supabase and Vercel deployments, but credentials, app environment files and deployed URLs are absent from this checkout. No production database mutation or paid provider request was made. Read [production upgrade](production-upgrade.md) for exact setup and rollout steps.

Remaining gates and limits:

- Review and apply only migration 009 to the existing eight-migration backend; then deploy the same app/worker commit. Do not reset or reseed production. The upgraded worker must replace the old worker before generation is enabled.
- Configure real Supabase environments, SMTP, Auth URL allowlists and admin MFA. Live upload/download, cross-user denial and final quotation acceptance remain to be verified against that environment. The connected Playwright scenario requires non-production test identities and is skipped by default.
- Provide a real Meshy API key, prepaid credits and supervised worker hosting. The pinned untextured model configuration has a documented credit estimate; actual consumed credits are recorded when available. THB allowances use an operator-reviewed conversion and do not guarantee or fabricate a provider money invoice. Reservations are conservative and not automatically refunded.
- Paid submissions with an uncertain outcome require manual reconciliation. Retrying them blindly is intentionally refused. Remote cancellation may be unavailable and does not guarantee a refund. Poll/retrieval retries reuse a persisted task ID.
- Uploads and provider outputs are capped at 4 MiB; meshes at 100,000 triangles, with additional GLB decoding/scene-depth limits. GLB is embedded, untextured triangle geometry with bounded scene transforms; external resources, compression/animation/skinning and image textures are rejected. 3MF archives remain unsupported. AI scale and physical printability require human review.
- Automatic slicer execution is not installed. Geometry estimates explicitly use infill/wall/throughput assumptions and are never exact material measurements. Final pricing requires reviewed slicer results and admin approval. Detail/finishing choices are recorded without invented calibrated surcharges.
- Spool-level allocation/reconciliation, low-stock messaging, production scheduling and automatic retention cleanup remain manual. Notifications are in-app. Deletion requests/larger archives require operator fulfillment. Gallery publication still requires separate consent and never occurs automatically from generation.
- PDF documents retain the existing Thai/English format. UI translations do not translate customer notes or supplied content. Legal tax-document fields, business registration, numbering and retention obligations need operator review. The application is not a full accounting ledger.
- Some service-role audit changes lack a JWT actor; operator-only configuration RPCs record the authenticated actor. Strict nonce CSP, independent penetration testing and separate-connection/distributed load tests remain outstanding. Embedded PostgreSQL tests validate SQL contracts but do not validate the hosted gateway or production concurrency under load.

A passing local build or synthetic browser fixture must not be described as a successful paid Meshy reconstruction, a verified hosted Supabase workflow or a verified Vercel deployment.
